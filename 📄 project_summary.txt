1. PROJECT OVERVIEW
================================================================================

OBJECTIVE:
Build a machine learning model to predict 30-day hospital readmission risk
and support clinical decision making with interpretable results.

DATASET:
• India Hospital Readmission Dataset (2015-2024)
• 120,000 patient admissions
• 8 clinical features including lab values and comorbidity indices
• 30-day readmission rate: 11.8% (realistic healthcare benchmark)

APPROACH:
• Comprehensive Exploratory Data Analysis
• Feature Engineering (age groups, comorbidity severity, risk scores)
• Multiple ML Models: Random Forest, XGBoost, Deep Learning
• Model Interpretability & Clinical Decision Support
